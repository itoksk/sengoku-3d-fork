みんなで合戦を増やしていきましょう

このデモはオープンソースです。地元の城、好きな合戦、「通説とは違う説がある」という話。だれでも GitHub から追加できます。GitHub がはじめての方の issue やプルリクエストの練習にも使ってください。

  1. 話してみる　「この戦いを入れてほしい」「ここは違う説がある」を issue に書く
  2. 諸説を足す　各ページの「諸説」→「諸説を追記する」から、ブラウザだけでプルリクエストが出せます
  3. 合戦をつくる　雛形をコピーして、陣の緯度経度と場面の文章を書けば1つの合戦になります
参加のしかたを読む issue を書く GitHub のリポジトリ
地形は国土地理院の標高データから作った実際の地形です（高さは強調）。軍勢の数・配置と地表の色分けは、通説にもとづく概念的な再現です。
